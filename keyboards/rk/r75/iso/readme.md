# Royal Kludge R75 ISO

* Keyboard Maintainer: [snakkarike](https://github.com/snakkarike)
* Hardware Supported: Royal Kludge R75 ISO
* Hardware Availability: [rk](http://www.rkgaming.com)

Make example for this keyboard (after setting up your build environment):

    qmk compile -kb rk/r75/iso -km via

Flashing example for this keyboard:

    qmk flash -kb rk/r75/iso -km via

To reset the board into bootloader mode, do one of the following:

* Hold the Reset switch mounted on the bottom side of the PCB while connecting the USB cable
* Hold the Escape key while connecting the USB cable (also erases persistent settings)
* Tap the Q key 3 times in Options Layer (Layer 2)

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
